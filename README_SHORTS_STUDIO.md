# 🏛️ WonkaShorts Studio (원카 숏츠 스튜디오)

> **원카AI(Wonka)**의 "AI 건축 쇼츠 30분 만에 만드는 법" 강좌(`https://youtu.be/ObvCtB1ATnA`)를 바탕으로 탄생한 **한 이미지 3분할 컷씬 연출 + 100% 독립형 원클릭 30일치 지식형 숏폼 대량 자동 제작 & 유튜브 자동 예약 시스템**

---

## 🌟 핵심 기능 및 특징

### 1. 원카AI & '신비한 건축사전' 시그니처 100% 재현
- **4단계 서사 구조**: Hook(충격 질문) → Problem(물리적/환경적 위기) → Solution(천재적 공학 해법) → Punchline(요약 & 구독 유도)
- **한 이미지 3분할 컷씬 연출 기술 (3-Panel Multi-Angle)**:
  - **CAM 01 (상단)**: 상황 발생 장소 및 거시적 광각 전경 (`● CAM 01 : 광각 전경 관측`)
  - **CAM 02 (중앙)**: 공학 구조 단면도해, 붉은색 타겟 레티클(`+`), 네온 치수선 측정 박스 (`↔ 400 TON`, `↔ 풍속 80m/s`)
  - **CAM 03 (하단)**: 물리 메커니즘, 부품 디테일, 지반 층 시뮬레이션 해석 (`● CAM 03 : 메커니즘 해석`)
  - **스마트 하이브리드 연출**: 도입 풀스크린 ➔ 문제/해결 3분할 다각도 컷씬 ➔ 요약 풀스크린으로 전환되어 지루함 원천 차단
- **인포그래픽 & 시각 연출**:
  - 9:16 (1080x1920) 고화질 세로형 숏폼 규격
  - 켄 번스(Ken Burns) 미세 줌인 카메라 무빙
  - 상단 `#신비한건축사전 [분야]` 공식 헤더 배지
  - 하단 반투명 볼드 고딕 한국어 2줄 자막
  - 긴장감 넘치는 앰비언트 테크 BGM 자동 믹싱

### 2. 원카AI 영상 분석 조언 & 시크릿 꿀팁 (Wonka Playbook) 내장
- **RULE 01: 구조 차용의 법칙 (ลอกโครง ไม่ลอกเนื้อ)** - 템포/서사만 빌리고 소재는 100% 독창적 제작으로 저작권 회피
- **RULE 02: 초반 3초 훅 & 3분할 컷씬** - 시각적 정보 밀도를 3배로 높여 이탈률 15% 미만 달성
- **RULE 03: 3분할 공간 배치 공식** - CAM 01(외경) ➔ CAM 02(단면&치수선) ➔ CAM 03(디테일) 수직 시선 유도
- **RULE 04: 색상 심리학** - 위기(네온 레드 `#FF3B30`), 기술(네온 사이언 `#38BDF8`), 수치(세이프티 옐로우 `#FFE600`)
- **RULE 05: 무공백(Tight Pacing) 텐션** - 문장 간 0.2초 이하 공백, 나레이션 100% + BGM 10% 덕킹
- **RULE 06: 유튜브 100점 SEO 자동화** - CTR 제목 3종 A/B + 설명란 타임스탬프 + 500자 태그 + 고정 댓글

### 3. API 크레딧 0원 (최소화) 무제한 제작
- **대본**: Gemini API 무료 티어(선택) 또는 **내장 오프라인 14개 엄선 지식 베이스**(API 키 없이도 100% 영구 무료 구동)
- **음성 (TTS)**: Microsoft `edge-tts` (100% 무료, 무제한 한국어 신경망 성우: 인준, 선희, 봉진, 현수)
- **비주얼**: `Pollinations.ai` (무료 무제한 Flux/SDXL 9:16 생성) + 비상 오프라인 블루프린트 그래픽 폴백
- **렌더링**: 로컬 FFmpeg (`imageio-ffmpeg` 내장 바이너리 활용으로 외부 설치 불필요)

### 4. 한 번에 30일치(주 3회 = 총 14편) 원클릭 대량 제작
- 클릭 한 번으로 한 달치 유튜브 쇼츠 콘텐츠(14개 영상 + 썸네일 + 자막)를 완전 자동 일괄 생성

### 5. 유튜브 자동 예약 업로드 & CSV 매니페스트
- 주 3회(월, 수, 금 18:00 KST) 골든 타임 자동 스케줄링
- **`youtube_batch_schedule.csv`** 자동 출력 (유튜브 스튜디오, 엑셀, TubeBuddy 연동 가능)
- Google YouTube Data API v3 연동 시 원클릭 비공개 예약 공개 등록 지원

## 🚀 실행 방법

### 방법 1: 윈도우 바탕화면 전용 아이콘 더블 클릭 (가장 추천)
바탕화면에 생성된 **`WonkaShorts Studio`** 바로가기를 더블 클릭하면 끝납니다!
- 자동으로 웹 서버가 실행되고 기본 인터넷 브라우저에 대시보드가 열립니다 (`http://localhost:8520`).

### 방법 2: 배치 파일 직접 실행
- 프로젝트 폴더에서 **`START_SHORTS_STUDIO.bat`** 파일을 더블 클릭합니다.
